- ✅ Вход/Выход из системы

- ✅ Запись на приём к врачу
- ✅ Просмотр своих записей с фильтрацией по статусу
- ✅ Просмотр медицинских записей (диагноз, назначения)

## 📋 Что можно попробовать:

1. **Зарегистрировать нового пациента**
   - Перейти на страницу регистрации
   - Заполнить все поля (включая группу крови)
   - Войти в систему

2. **Просмотреть врачей**
   - Открыть список врачей
   - Использовать фильтр по специализации
   - Найти врача по имени

3. **Записаться на приём**
   - Выбрать врача
   - Указать дату/время (согласно расписанию)
   - Описать жалобы
   - Отправить запись

4. **Оставить отзыв**
   - Открыть карточку врача
   - Поставить оценку (1-5 звёзд)
   - Написать комментарий

5. **Через админку создать медицинскую запись**
   - Войти в админку
   - Найти завершённую запись (или изменить статус на "completed")
   - Добавить диагноз и назначения
   - Пациент увидит это в "Моих записях"

## 🔧 Технические детали:

### Используемые технологии:
- **Backend**: Django 4.2
- **Frontend**: HTML5, CSS3, Bootstrap 5
- **База данных**: SQLite
- **Иконки**: Font Awesome 6.4
- **Язык интерфейса**: Русский

### Основные модели:
- UserProfile (пациенты)
- Specialization (специализации)
- Doctor (врачи)
- Schedule (расписание)
- Appointment (записи на приём)
- MedicalRecord (медицинские записи)
- DoctorReview (отзывы)

## 📝 Примеры использования:

### Регистрация нового пациента:
1. Нажать "Регистрация" в меню
2. Заполнить форму:
   - Имя пользователя: patient1
   - Email: patient1@mail.ru
   - Имя: Анна
   - Фамилия: Иванова
   - Дата рождения: 01.01.1990
   - Телефон: +7 (999) 123-45-67
   - Адрес: Москва, ул. Ленина, д. 1
   - Группа крови: A+ (II) Rh+
   - Пароль: qwerty123
3. Нажать "Зарегистрироваться"

### Запись на приём:
1. Войти под своим аккаунтом
2. Перейти в "Врачи"
3. Выбрать врача и нажать "Подробнее"
4. Проверить расписание
5. Нажать "Записаться на приём"
6. Выбрать дату/время (например, понедельник в 10:00)
7. Описать жалобы
8. Отправить
