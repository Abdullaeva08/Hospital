## 🎯 Как запустить проект (3 способа)

### Способ 1: Двойной клик (самый простой) 🖱️

1. Найдите файл `запуск.bat` или `запуск.ps1` в папке проекта
2. Дважды щёлкните по нему
3. Откроется окно — сервер запустится автоматически

### Способ 2: Через PowerShell

```powershell
cd c:\Users\user\Desktop\Hospital
.\запуск.ps1
```

### Способ 3: Через командную строку

```powershell
cd c:\Users\user\Desktop\Hospital
venv\Scripts\python.exe manage.py runserver
```

---

## 🔄 Команды для работы

```powershell
# Запустить сервер
py manage.py runserver

# Проверить ошибки
py manage.py check

# Создать новые миграции (после изменения models.py)
py manage.py makemigrations

# Применить миграции
py manage.py migrate

# Открыть интерактивную консоль Django
py manage.py shell
```
